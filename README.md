# 代辦事項 MVP

一個單檔、零依賴的網頁代辦事項清單。打開 `index.html` 就能用，資料保存在瀏覽器本機。

## 專案解決什麼問題

想快速記下幾件待辦、完成後打勾，卻不想註冊帳號、安裝 App 或依賴網路服務。這個專案提供最小可用的清單功能，沒有多餘設定。

## 主要功能

- 新增待辦事項（按 Enter 或點「新增」）
- 勾選標記完成，文字加上刪除線
- 刪除單一事項
- 顯示「未完成 / 總數」統計
- 資料以 localStorage 保存在瀏覽器，重新整理或關閉後再開仍保留

不包含：編輯文字、排序、篩選、多份清單、雲端同步、帳號系統。

## 安裝方法

無需安裝任何套件。取得專案檔案即可：

```
Todo-mvp/
├── index.html   # 整個應用程式（HTML + CSS + JavaScript）
├── README.md
└── LICENSE
```

需求：任一現代瀏覽器（Chrome、Edge、Firefox、Safari）。

## 使用方法

### 方式一：直接開啟

在檔案總管雙擊 `index.html`。

### 方式二：本機伺服器（建議）

部分瀏覽器對 `file://` 有儲存限制，用本機伺服器可避免：

```bash
python -m http.server 8765
```

然後開啟 <http://localhost:8765>。

### 操作

1. 在輸入框輸入文字，按 Enter 或點「新增」。
2. 點左側方框切換完成狀態。
3. 點右側「×」刪除該項。

## 輸入輸出範例

### 新增

| 輸入 | 輸出 |
| --- | --- |
| 輸入「買牛奶」後按 Enter | 清單出現「☐ 買牛奶」，底部顯示「1 項未完成 / 共 1 項」 |
| 再輸入「寫週報」後按 Enter | 清單為「☐ 買牛奶」「☐ 寫週報」，底部顯示「2 項未完成 / 共 2 項」 |
| 輸入空白或只有空格 | 不新增，清單不變 |

### 完成與刪除

| 操作 | 輸出 |
| --- | --- |
| 勾選「寫週報」 | 顯示為「☑ ~~寫週報~~」，底部顯示「1 項未完成 / 共 2 項」 |
| 點「買牛奶」右側的 × | 清單只剩「☑ ~~寫週報~~」，底部顯示「0 項未完成 / 共 1 項」 |
| 刪除全部項目 | 顯示「目前沒有待辦事項」 |

### 儲存格式

資料存在 localStorage 的 `todos` 鍵，內容為 JSON 陣列：

```json
[
  { "id": 1789012870927, "text": "寫週報", "done": true },
  { "id": 1789012871019, "text": "回覆客戶 email", "done": false }
]
```

清除瀏覽器網站資料即可重置清單。
